
# ACPI-S0-S5&G0-G3

在 **ACPI（高级配置与电源接口）** 规范中，**G0 到 G3** 代表计算机系统的 **全局电源状态（Global System Power States）**：

| ACPI 全局状态 | 名称 | 对应 S 状态 | 硬件与供电状态 | 常见唤醒/切换方式 |
| :---: | :---: | :---: | --- | --- |
| **G0** | **Working**<br>(工作状态) | **S0** | 整体正常供电，操作系统全面运行，CPU 正常执行代码。 | <br>切换G1：短按电源键<br>切换G2：长按电源键(5.1s或以上) |
| **G1** | **Sleeping**<br>(睡眠状态) | **S1, S2, S3, S4** | 系统低功耗挂起。<br>• **S1** (Power On Suspend / POS - CPU 逻辑挂起)：现代硬件基本弃用。<br>CPU 状态：CPU 停止时钟（Clock Stopped），但 CPU 核心与缓存依然保持供电。CPU 自身的寄存器和上下文完全保留在 CPU 芯片内部。<br>内存状态：内存（RAM）维持供电并正常刷新。<br>特点：功耗相对较高（只是停止了计算），但唤醒速度最快（微秒/毫秒级），唤醒时 CPU 无需重新初始化。<br>• **S2** (CPU Off - CPU 彻底断电)：硬件极少实现，大多直接跳到 S3。<br>CPU 状态：CPU 彻底切断电源。在断电前，CPU 将 dirty 缓存数据写回 RAM，内部寄存器和上下文全部丢失。<br>内存状态：内存（RAM）依然维持供电并刷新，用于保存操作系统和 CPU 的上下文数据。<br>特点：功耗低于 S1，唤醒时系统需要重新给 CPU 上电并从 RAM 中恢复 CPU 现场，唤醒时间稍长。<br>• **S3** (Suspend to RAM)：<br>内容留存内存，其余断电。当唤醒后（S3->S0）状态，用户刚刚的工作可以恢复到睡眠前的相同状态。但是在这个状态下如果突然AC掉电，这样用户此前处理的数据将会丢失。<br>• **S4** (Hibernate)：<br>内容写入硬盘，系统基本断电。当唤醒后（S4->S0）状态，用户刚刚的工作可以恢复到睡眠前的相同状态。但是在这个状态下如果突然AC掉电，这样用户此前处理的数据将不会丢失，再次重启后依然能够恢复进入睡眠模式前的工作状态。 | 切换G0：短按电源键（或按键、鼠标、网络包（WOL）、定时器） |
| **G2** | **Soft Off**<br>(软关机) | **S5** | 操作系统已安全关闭，主电源断开，但**保留 5VSB（待机电源）**给 BMC、网卡和电源按键供电。 | 切换G0：短按电源键、BMC IPMI/Redfish 命令、WOL |
| **G3** | **Mechanical Off**<br>(物理断电) | **无**<br>(Hard Off) | **AC 交流电源彻底拔掉**或关闭电源开关，5VSB 完全断电。<br>仅依靠 RTC 纽扣电池维持主板时钟与 CMOS 配置。 | 切换G0：重新插上电源线并通电 |
